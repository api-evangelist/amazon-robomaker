AWS RoboMaker is a cloud-based service that makes it easy to develop, simulate, and deploy intelligent robotics applications. RoboMaker extends the most widely used open-source robotics software framework, Robot Operating System (ROS), with connectivity to cloud services, providing tools for building, testing, and deploying robotics applications at scale.

**Areas:** AWS · Robotics · Simulation · Defunct
